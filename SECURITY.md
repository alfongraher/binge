# Security

Use the latest beta build; security fixes are not automatically backported to older installers. The current security update is 0.4.2 (11). Update both devices when using local-network sync.

A focused review and its limits are documented in [the security review](docs/SECURITY-REVIEW.md). Do not post credentials, source URLs with access tokens, private history, or detailed exploit instructions in public issues. Contact the repository maintainer privately for a suspected vulnerability; ordinary bugs can be reported in Issues with sensitive information removed.

The app processes third-party network responses and media. No-account use does not mean anonymity: providers and torrent peers can observe network addresses and content requests.
