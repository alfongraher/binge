Public Beta 1 for Mac and iPad: version 0.4.1 (10).

Includes Home with Continue Watching and featured artwork, scrolling Explore with genres, library favourites and labels, subtitles, Picture in Picture, next-episode playback, and optional local-network history/library synchronization.

- **iPad:** download the `.ipa`. Use a compatible signing tool with your own Apple Account; the organizer’s development signature is not valid for all devices. The corrected Explore pagination build is included. AltStore installation has not yet been verified on a fresh tester device.
- **Mac:** download the Mac ZIP, extract binge.app and copy it to Applications. Requires Apple silicon and macOS 14 or later. This is a development-signed, non-notarized build.

Read `docs/USER-GUIDE.md` in the repository for setup, features, limitations and feedback instructions. iPad playback is standalone; no Mac server is required. Credit completion uses an estimate, not detected credit timestamps.
